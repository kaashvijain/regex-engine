Train describer

Reading the panel

  • Lit lamp — a state the machine could be in after the characters read so far.
  • Double ring — the accepting state. Green when the train stops on it.
  • Solid track — consumes one character matching its label.
  • Dashed track — an ε-move, taken for free.
  • Lit track — the moves taken on the last character.

The NFA runs every possible route at once (Thompson simulation). The DFA tab pre-computes those sets of states, then minimizes the result.
